# Prototype handoff

Prototype aktif menggunakan React + Vite dan dijalankan dari root project dengan `npm run dev`.

- `src/components/` — shell portal, navbar, drawer mobile, dan komponen UI.
- `src/pages/` — dashboard overview, production, fleet, logistics, dan SQL Lab.
- `src/styles/avian.css` — design token Avian yang diadaptasi ke warna Freeport/PTFI.
- `public/brand/` — logo Freeport/PTFI lokal.
- `snowflake/` — setup warehouse, seed data, dan latihan query.
